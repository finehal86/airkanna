1. LPを「目に留まるもの」にするための工夫

最大の課題：実写コンテンツが一切入っていない
現状のLPの「ビフォーアフター」（index.html 224〜236行目、388〜392行目）はすべてCSSグラデーションで木目を模した仮の見た目。動画も（index.html 543行目）<!-- ← src="./videos/施工ビフォーアフター.mp4" を追加してください -->とコメントがあるだけで、実際の動画ファイルは未挿入。デザインとコピーの骨組みはできているが、最も訴求力が必要な実写素材がゼロの状態。

実写差し替え（最優先）

  • 実際のBefore/After写真・動画を入れる。木材再生は「目に見える変化」が価値そのものなので、文章より1枚の実写の方が何倍も説得力を持つ
  • 施工事例カード（神社仏閣・古民家・ログハウスの3枚、index.html 710〜730行目付近）も今はCSSの色面のみ。実際の現場写真に差し替える
  • 会社概要セクションのGoogleマップが「準備中」のまま。実際の地図に差し替えると信頼性が上がる

デザイン・構成面での追加の工夫

  • お客様の声・第三者評価がない：施主や寺院・古民家所有者からの推薦コメント、施工件数（「施工実績◯件」等の数字）を入れると社会的証明が強化される
  • 代理店40社の実在性を見せる：ロゴ一覧や地図上のピン表示があると「全国対応」の説得力が増す
  • 電話番号が見当たらない：LINE一本に絞る戦略は理解できるが、年配の神社仏閣関係者・古民家所有者は電話を好む層もいるため、補助的に電話番号を併記した方が離脱を防げる可能性がある
  • 動画はLPだけでなくSNS広告素材としても使えるので、15〜30秒のショート版を別途切り出すと一石二鳥

2. SNS広告のためのSEO対策・その他設定

このLPはSNS広告の受け皿（ランディングページ）としての性質が強いので、検索SEOよりまず広告効果計測と信頼性メタ情報の整備が優先度高め。

今すぐ直すべき仮設定（本番公開前に必須）

  • <link rel="canonical" href="https://example.com/">（8行目）→ 本番ドメインに差し替え
  • og:url（14行目）も同様に本番URLへ
  • og:image（15行目）が https://example.com/ogp.jpg のまま → SNSでシェア・広告表示される時のサムネイル画像（1200×630px推奨）を実際に用意してアップロードしないと、リンクシェア時に画像が表示されない
  • twitter:title / twitter:description / twitter:image が未設定（twitter:cardのみ）→ 追加推奨

構造化データ（JSON-LD）の強化

22〜39行目にHomeAndConstructionBusinessのスキーマが既にあるが、telephone、image、sameAs（Instagram/Facebook/LINEのURL一覧）を追加すると検索結果やナレッジパネルでの表示が強化される。

計測系

  • Meta Pixel / Conversion APIの設置（広告効果測定。現状未設置）
  • LINEボタンのクリックをコンバージョンイベントとして計測
  • 流入元ごとに効果を見たい場合はLINE URLに?utm_source=instagram等のUTMパラメータを付与

SNS広告特有でやっておくと良い設定

  • Googleビジネスプロフィールの登録（地域性のあるサービスなので、広告経由で会社名検索した人への信頼補強になる）
  • Instagram/FacebookのプロフィールページにもLP・LINEリンクを設置
  • ハッシュタグ戦略（#古民家再生 #神社仏閣 #ログハウス など、ターゲット層が検索・閲覧する語）
  • LINE広告という選択肢もあり、Instagram/FB広告と並行して回すとLINE登録への導線がより直接的（同じLINEプラットフォーム内で完結するため）

通常SEO（検索エンジン経由の流入も狙う場合）

  • sitemap.xml / robots.txt は今のところ存在しない（単発LPなら必須ではないが、コーポレートサイトと合わせて運用するなら用意）
  • 表示速度（Core Web Vitals）：動画を追加すると重くなるので、preload="metadata"や軽量フォーマット（WebM/H.264圧縮）を検討
  • 現状画像（<img>タグ）が1つも使われていないため、実写を追加する際はalt属性を必ず付与（アクセシビリティ＋画像検索SEOの両方に有効）
着手の優先順位：
① 実写動画・写真の差し込み　→　② og:image/canonical等の本番値差し替え　→　③ Pixel設置　→　④ それ以外のSEO
